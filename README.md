Zenze is a token launchpad for Robinhood Chain and Arc.

A new token is minted to its own curve. You can buy it and sell it back into the same curve. The fee, the creator share, and the $ZNZF pool rules are in the docs, not in the marketing lines. The live $ZNZF curve does not migrate.

This repository is public. Do not commit API keys, cookies, or private keys.
